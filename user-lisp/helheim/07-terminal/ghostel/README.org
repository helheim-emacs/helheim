* helheim-ghostel

Install and cofigure [[https://github.com/dakra/ghostel][Ghostel]] — a [[https://github.com/ghostty-org/ghostty][libghostty]]-powered terminal emulator.

** Enable
#+begin_src emacs-lisp
(require 'helheim-ghostel)
#+end_src

** Packages
- [[https://github.com/dakra/ghostel][ghostel]]
- [[https://github.com/anuvyklack/hel-ghostel][hel-ghostel]]

** Usage

- =SPC o t= ::
  - Start a new terminal or switch to an existing one.
  - With =M-u=, always create a new terminal.

- =SPC p t= :: Start terminal in the current project's root.

See [[https://github.com/anuvyklack/hel-ghostel][hel-ghostel]] documentation for how Ghostel and Hel are integrates.
